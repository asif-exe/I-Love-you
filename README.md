#I Love You--- Heart Animation ❤️

A small Python project that recreates a heart shape using 100 animated "I love you" text elements.

The animation uses Pygame, with soft pink text, a subtle glow effect, and smooth movement on a black background.

## Features
- 100 animated text elements
- Smooth horizontal and vertical movement
- Soft pink gradient typography
- Subtle glow and shadow effects
- Resizable animation window

## Requirements
- Python 3
- Pygame

Install Pygame:

```bash
pip install pygame
```

## Run

```bash
python love_heart.py
```

## Controls
- `SPACE` – Pause / Resume
- `ESC` – Exit

Made with Python and Pygame. ❤️
